# nousarchy

Light theme for [Omarchy](https://omarchy.org).

## Contents

| File | Purpose |
| --- | --- |
| `colors.toml` | Full Omarchy palette (accent, backgrounds, foregrounds, ANSI + bright ANSI) |
| `icons.theme` | Icon theme name (currently `Yaru-purple`) |
| `backgrounds/` | Wallpaper set used with the theme |

## Install

Link the theme into your Omarchy themes directory:

```sh
ln -s ~/.config/omarchy/themes/nousarchy ~/.config/omarchy/themes/nousarchy
```

Then select `nousarchy` from the Omarchy theme picker.

## Colors

- Mode: `light`
- Accent: `#0000f2`
- Selection: `#f2f200`
- Background: `#f5f5f5` / dark `#ececec` / darker `#dedede`
- Foreground: `#212121` / bright `#000000`
